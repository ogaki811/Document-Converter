# ドキュメント変換アプリ 基本仕様書

## 1. 概要
本アプリケーションは、ExcelおよびWordファイルをブラウザ上で**画像ファイル (PNG)**に変換するWebツールです。
サーバーサイドでのファイル処理を行わず、すべての変換処理をクライアントサイド（ブラウザ内）で完結させることで、高いセキュリティとプライバシー保護を実現しています。

## 2. 機能一覧

### 2.1 ファイルアップロード
- **ドラッグ＆ドロップ**: 画面内の指定エリアにファイルをドラッグ＆ドロップしてアップロード。
- **ファイル選択ダイアログ**: クリック操作によるファイル選択も可能。
- **複数ファイル対応**: 一度に複数のファイルをリストに追加可能。
- **バリデーション**:
  - 対応拡張子: `.xlsx`, `.xls` (Excel), `.docx` (Word)
  - **注意**: 旧形式の `.doc` ファイルは非対応です。
  - 非対応ファイルは自動的に除外。

### 2.2 ファイル変換機能
以下のライブラリを使用して、アップロードされたファイルを画像へ変換します。
- **Excel変換**: 
  - ライブラリ: `SheetJS (xlsx)`
  - 処理: シートのデータを解析し、HTMLテーブル構造へ変換後、画像化。
  - 対象: ワークブックの先頭シート。
- **Word変換**:
  - ライブラリ: `Mammoth.js`
  - 処理: `.docx` ファイルの構造を解析し、HTMLへ変換後、画像化。
  - スタイル: 基本的な文書構造を維持しつつ、画像用に見やすく整形。
- **画像生成**:
  - ライブラリ: `html2canvas`
  - フォーマット: PNG
  - 背景色: 白

### 2.3 UI/UX
- **モダンデザイン**: Tailwind CSS (v4) を使用したダークモードベースのプレミアムなデザイン。
- **インタラクション**:
  - ドラッグ＆ドロップ時の視覚的フィードバック（ハイライトなど）。
  - Framer Motionによるスムーズなリスト表示アニメーション。
- **ステータス表示**:
  - 待機中 (Idle)
  - 処理中 (Processing...) - ローディングアイコン表示
  - 完了 (Done) - 成功アイコン表示
  - エラー (Failed) - エラーアイコン表示
- **操作**:
  - 「Convert」ボタンで個別に変換開始。
  - 「×」ボタンでリストから削除。

## 3. 技術スタック

| カテゴリ | 技術・ライブラリ | 用途 |
| --- | --- | --- |
| **Framework** | React 19 | UI構築 |
| **Build Tool** | Vite | 高速な開発環境・ビルド |
| **Styling** | Tailwind CSS v4 | スタイリング |
| **Animation** | Framer Motion | UIアニメーション |
| **Icons** | Lucide React | アイコン表示 |
| **Excel Logic** | SheetJS (xlsx) | Excelファイルの読み込み・解析 |
| **Word Logic** | Mammoth.js | WordファイルのHTML変換 |
| **Image Logic** | html2canvas | HTMLからの画像生成 |

## 4. セキュリティ仕様
- **クライアントサイド処理**: アップロードされたファイルは一切外部サーバーへ送信されません。すべての処理はユーザーのブラウザメモリ内で行われます。
- **データ保持**: 変換後のデータはブラウザをリロードまたは閉じると破棄されます。

## 5. 動作環境
- **ブラウザ**: 最新版の Google Chrome, Firefox, Safari, Edge
- **JavaScript**: 有効であること
